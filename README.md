# The Stylistic Slope: Algorithmic Homogenization and the Decolonization of Literary AI
‌
This repository contains the replication package and methodological framework for the paper: *"The Stylistic Slope: Algorithmic Homogenization and the Decolonization of Literary AI"*.
‌
## Project Overview
This research investigates the systematic failure of LLMs (specifically GPT-4) to replicate the linguistic nuances of high-context, non-Western literary traditions (Persian and Post-Colonial).
‌
## Repository Structure
- `/scripts`: Python implementation for stylometric metrics (TTR, MLS, Hapax Legomena).
- `/framework`: Documentation of the Burrows’ Delta Framework and scoring guidelines.
- `/prompts`: The Zero-shot and Few-shot prompting protocols used in the study.
- `metadata_summary.md`: Quantitative results for Hemingway, Achebe, and Hedayat cohorts.
‌
## Core Metrics
- **Type-Token Ratio (TTR):** Measuring lexical richness.
- **Mean Length of Sentence (MLS):** Assessing syntactic complexity.
- **Burrows’ Delta:** Quantifying stylistic distance from the source corpus.
